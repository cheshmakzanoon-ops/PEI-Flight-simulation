# Regenerating the Expanded farmland v2 archive

These tools regenerate a sparse optical mask from pinned public data. The output goes into a scratch directory first. No manual warping, older mask, Google imagery, or map key is needed. Do not commit the raw GPKG, TIFFs, private intermediate owner list, or the unpacked terrain witness.

## Inputs

Install the locked Node dependencies (`npm ci`, Node 22.12+) and Python 3 with GDAL/OGR, NumPy, SciPy and Matplotlib. Follow the [crop-source guide](../crop-preview/README.md) to fetch the original [2023 PEI field detections](https://agriculture.canada.ca/atlas/data_donnees/fieldBoundaries/data_donnees/gpkg/pe_oneSoil_field_boundaries_2023.gpkg) and the [2025 PEI crop/confidence rasters](https://agriculture.canada.ca/atlas/data_donnees/annualCropInventory/data_donnees/tif/2025/aci_2025_pe_v1.zip). For province v2 you only need those **three source files** and the screening step below. The already-authenticated CC0 optical texture in the game is reused, not regenerated by this tool.

## Rebuild and compare

Run from the repository checkout. Use a Python interpreter that has the Debian/conda GDAL bindings if your machine has more than one. For the release the qualifier and packer ran under CPython 3.13; a second CPython 3.12 pack returned byte-identical copies of *every* pack, index and manifest. Each gzip member has a zero timestamp and an explicitly normalized RFC 1952 OS byte. Different zlib implementations can still produce different streams; use the final byte checks, not only a sample count.

```sh
set -eu
ROOT="$PWD"
SRC="/absolute/path/to/downloaded-source"
WORK="$(mktemp -d)"
PYTHON=/usr/bin/python3  # or your Python with GDAL, NumPy, SciPy, Matplotlib

"$PYTHON" tools/geodata/crop-preview/screen-fields.py --source "$SRC"
./node_modules/.bin/esbuild tools/geodata/province-fields/actual-world.mjs \
  --bundle --platform=node --format=esm '--define:import.meta.env.BASE_URL="./"' \
  --outfile="$WORK/actual-world.mjs"
(
  cd "$WORK"
  node actual-world.mjs "$ROOT" "$SRC/supported-fields.json"
  PEI_RECON="$SRC" PEI_WORLD="$ROOT/public/world" PEI_THREE_WITNESSES="$WORK" \
    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
    "$PYTHON" "$ROOT/tools/geodata/province-fields/qualify.py"
  "$PYTHON" "$ROOT/tools/geodata/province-fields/pack-field-shards.py" \
    private-1km-mask.npz packed
)
diff -qr "$WORK/packed" public/world/fields-province/v2
node --experimental-strip-types tools/geodata/province-fields/verify-field-archive.mjs \
  "$WORK/packed" "$WORK/decoded-receipt.json"
node --experimental-strip-types --test test/province-field-requalification.test.ts
```

The Node exporter imports the simulator’s own world projection and actual N112 mesh. It emits signed projection test points across all four quadrants, road/walk/parking/runway geometry, local terrain collars, the real clipped Confederation Trail footprint and the same protected-geometry contract used by the runtime. The Python qualifier verifies input hashes, measures full bilinear support against original polygons, native classification and current terrain triangles, then excludes conflicts before committing any 4 m support. The packer checks equality across cardinal and diagonal two-cell halos. The [staged qualification counts](../../../docs/qa/farmland-v2/source-qualification.json) report what survives each step.

A release match is indexed by `a77f319fba8091c2d06b913af5c2cd0ef58a695e1147f45de51295039f5d524a` on the wire and `aa037e64ea3d04a9fc96517d997e28164ea00fcc80411ae6ccac9f9d842f5a52` decoded. The real runtime reader independently checks every returned range, its uncompressed RG8 payload and the retained centre count.

## Additional checks

* **County accounting** is separate from rendering. Use the [PEI county polygon service](https://gis.princeedwardisland.ca/server/rest/services/county_zones/MapServer/0), all features, fields `KEYWORD,USERNUM`, GeoJSON in EPSG:4326, with 6 decimal places. The source hash guards the exact snapshot used in the [published census](../../../docs/qa/farmland-v2/county-census.json); a later administrative update requires review. Run:
  ```sh
  "$PYTHON" tools/geodata/province-fields/county-census.py \
    --county "/path/to/county-raw.geojson" --pack "$WORK/packed" \
    --owners "$WORK/field-slope-by-owner.json" --world "$WORK/actual-stock.json" \
    --out "$WORK/county-census.json"
  ```
* **Cache rollover:** for a real retired index from Git history, verify both representations in both readers:
  ```sh
  git show 6cc58ecd707881269bd79198af7eff9a613e2155:public/world/fields-province/index.fcr.gz > "$WORK/retired.fcr.gz"
  node --experimental-strip-types tools/geodata/province-fields/verify-directory-rollover.mjs \
    "$WORK/retired.fcr.gz" "$WORK/packed/index.fcr.gz" "$WORK/rollover.json"
  ```
* **Grass and crops:** `python tools/qa/province-land-support.py public/world` authenticates both complete archives and counts exact and possible bilinear overlaps without a browser.
* **Runtime:** `tools/qa/province-fields-player.py`, `province-fields-crossing.py`, `province-fields-corner.py`, `province-fields-frames.py` and `province-land-player.py` exercise the versioned archive in the real player. Use `--help` for required Chromium, checkout/dist and output paths. [Current release evidence](../../../docs/qa/province-fields.md) distinguishes these checks from the retired v1 art boards.

The FCR1 layout is deliberately unchanged: signed X/Z indices, a bounded pack table, immutable range sizes and SHA-256 pins for wire and decoded RG8 data. A 1,024 m tile contains 256 × 256 four-metre samples plus a two-cell border on each side. The shader reads a discrete authored direction from R and filters coverage G. No source photographs, survey point clouds or personal farm data are carried by this format.
