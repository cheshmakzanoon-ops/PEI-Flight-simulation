This is an **unplaced representative Three.js model**, not a surveyed shell, map patch, installed asset, photogrammetry, or simulator comparison. The exact existing owner has not been altered. ## Original art and reproduction

`north-cape-visitor.ts` creates one **unparented** group / one ordinary opaque mesh; 1,240 triangles (104,160 bytes of F32 attrs), one draw, no atlas, network, texture fetch or raw image dependency. The volume is authored in local metres, 28.11×20.78 m bounding plan and 8.109 m high. No world pose or receiver supplied. The glazed shoulders step by .90 m in this relative studio shape. Their physically raised pale mullions have dark rebates, clean light directions and opaque softened analytical reflection, with no depicted interior. The two roof pitches are source-bounded; the visible ridge fold, low post-supported canopy and elevated cedar glazing monitor are closed authored objects. Low-frequency cedar and filtered metal lines are procedural. Unseen walls are deliberately neutral/simple. The unshaded/disabled studio floor is synthetic and not original North Cape ground.

Test from this directory with Node 24, the repository’s installed Three.js r187, Python 3 with NumPy/Pillow, and Mesa EGL for the studio proof. All output directories must be fresh:

```sh
node --experimental-strip-types --test verify-frontage.mjs
node prove.mjs /tmp/pei-visitor-new-studio
# Optional independent stock source replay from this package directory:
node owner-replay.mjs ../../.. /tmp/pei-visitor-stock-new.json
```

The [front](evidence/front.webp), [porch](evidence/porch.webp) and [small-footprint](evidence/visibleScale.webp) plates are lossless copies of the actual original studio pixels. The source PNG, decoded RGBA, distributed WebP hashes and exact Mesa witness are recorded alongside them. Isolated ES3 uses the actual packed geometry and shaders, 4× RGBA8/D24 and literal draw; floor-only restore is byte-identical and alpha exact. The shot at simulated 53° optics is similar in on-screen width to the archived stock aperture but is **not** a source-matched flight A/B. Tests cover 101 oriented closed components; those with authored embedding deliberately intersect, not a boolean union or a collision mesh. All reference files are excluded from the tested art source. Use the declared local or rigid/uniform-scale frame; the study shader is not a nonuniform remapping or material calibration.
