# Cavendish detail

In Dispatch, choose **Cavendish Dunelands · coastal pass**, then select
**Enable Cavendish detail**. This reloads the same project and retains the
departure, other options, and existing standalone study selections.
Use **Turn off Cavendish detail** to remove only the regional package.
The URL equivalent is `?cavendishDetail`.

| Included study | Scope |
| --- | --- |
| [Green Gables House](../art/green-gables-house.md) | Near-field exterior at its existing atlas owner. |
| [Green Gables Barn](../art/green-gables-barn-review.md) | Separate near-field Barn and adjoining wing. |
| [Lake of Shining Waters](cavendish-water.md) | The supported 2020 freshwater core, not the whole or contemporary lake. |
| [Southwest dry rise](gables-southwest-grade.md) | Grade and contact in one independently qualified native area. |
| [Fairway colour](gables-fairway.md) | A protected portion of the existing open fairway. |
| [Gravel connection](gables-trail.md) | Material only on the supported mapped path trace. |

Cavendish detail is off by default and separate from the Detailed preset.
It leaves advanced alternate inland terrain, survey relief and building-shadow
settings alone; those settings suspend the pack. Each individual study
still uses its original source and availability checks. The visitor centre,
full grounds and current shoreline are not part of this package.

[The production replay](cavendish-package.json) enabled all six studies
and flew 74.74 m from the normal departure. It verified that turning the
package off kept separate manual selections, that the incompatible terrain
choice blocked it, and that the mobile button met a 44 CSS-pixel tap
target without horizontal overflow. This is a functional flight and
controls check, not a hardware graphics or frame-rate measurement.
