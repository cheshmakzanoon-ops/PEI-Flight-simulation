# Cape Tryon far foliage: HOLD

The [small-footprint foliage workbench](../../../tools/art/grain-corn-far-proof/)
passed an isolated transport comparison. A separate real **Cape Tryon
cliff pass** checked whether that treatment worked on original
simulator terrain. It does not ship.

The 264 original clumps were a bounded test of part of one signed
2025 role, not the full field or a claim of current planting. The
two source shapes were rebaked against the actual world sun. The
test preserved the stock departure, Chase lens, terrain, object
submission and flight controls. At actual native 1× the treatment
looked like a bright stippled swatch on a darker whole field. The
boundary did not read as a crop boundary. This is a visual **HOLD**,
not a failure to initialize a renderer or a prettier version.

| Ordinary travel | Marked pixels | Four changed samples |
| --- | ---: | ---: |
| 974.302 m | 2,944 | 0 |
| 1,017.799 m | 5,290 | 0 |

The visible changes resolved to one, two or three samples on the
**actual default 4× target**. No pixel established the required
all-four authored sample, so the original optical rule also remains
held. Independent calibration used a **separate** synthetic opacity
control to verify all four sample classes, A133 preservation, actual
front and back occluders in both orders, and depth untouched by
discard. It does not change the authored output or waive the rule.
The full field, old neighbouring ownership, scene cost and true
original-geometry parity are still unapproved.

See [the native receipt](cape-far-native-hold-receipt.json) and
[unscaled old and authored native crops](cape-far-native-1x.png).
These are from the same two real Chase frames, not upsampled studio
renders. Original, discarded and restored frames are byte-exact;
the late control is wholly original after the physical envelope
leaves the view. Future work on continuous field optics and a
direct geometry comparison is separate from this held treatment.
