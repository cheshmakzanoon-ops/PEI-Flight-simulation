# 571 Main Street roof fit

The native receipt pins the scoped classified CanElevation 2020 point cloud
window, retained building atlas feature and the fitted roof planes. The same
original metre-scale data, not a photography asset, define both the geometry
and its held-back spatial checks. A small mapping witness is
[licensed separately](../odbl/montague-macdonald).

Natural Resources Canada source data are available under the
[Open Government Licence – Canada](https://open.canada.ca/en/open-government-licence-canada).
The source point cloud and the whole OSM extract are not bundled.
See the [implementation and QA notes](../../docs/qa/montague-macdonald.md).
