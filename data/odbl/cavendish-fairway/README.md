# Bounded Cavendish fairway source

[OpenStreetMap way 1353393025](https://www.openstreetmap.org/way/1353393025),
version 1 (2025-01-22), identifies this mapped fairway polygon. © OpenStreetMap
contributors. The adapted boundary and derivative geographic mask are available
under the [Open Database Licence 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

The intersecting one-metre source clearance comes from [NRCan CanElevation](https://open.canada.ca/data/en/dataset/957782bf-847c-4644-a757-e383c0057995).
Contains information licensed under the [Open Government Licence – Canada](https://open.canada.ca/en/open-government-licence-canada).
The vegetation evidence is a non-imagery summary of Sentinel-2 observations:
contains modified Copernicus Sentinel data 2024–2026. It is not a species survey,
verified access, mowing plan, or current management statement. Refer to
[the release guard and replay instructions](../../../docs/qa/gables-fairway.md).
