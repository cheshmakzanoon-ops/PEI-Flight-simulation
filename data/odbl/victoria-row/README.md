The small JSON file contains only fifteen public OSM way IDs and their exterior
building rings and one exact three-node portion of public Richmond Street
way 431213352 between Queen and Great George streets in Charlottetown, PEI.
Coordinates are WGS84 `[longitude, latitude]`, with ring closure implicit.
No private or contributor identifiers, photo imagery, address joins, tenancy
or point-of-interest labels are used. The nearest-owner fill inside the NRCan
shell bridges slight source outline disagreements; it does not extend the
outer boundary or create new OSM geometry outside the scoped envelope.
