# Cavendish gravel connection source

[OpenStreetMap way 704985291](https://www.openstreetmap.org/way/704985291),
version 2 (2022-03-06), independently qualifies the trace as a mapped
gravel path. Adapted geometry © OpenStreetMap contributors, available
under the [Open Database Licence 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
This is not a surveyed width, current access, or post-Fiona works record.

The coordinate cut, protected source intersections and scope are documented
in the [rendering notes](../../../docs/qa/gables-trail.md).
