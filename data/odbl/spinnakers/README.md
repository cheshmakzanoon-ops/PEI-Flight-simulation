# Spinnakers’ Landing geometry (ODbL 1.0)

© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). This scoped extracted database is available under the [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). `footprints.json` holds the geographic inputs from the Geofabrik Prince Edward Island snapshot dated 1 November 2026. It includes a tagged wooden pier and seven building/canopy outlines. It excludes contributor metadata.

The [runtime and source notes](../../../docs/qa/spinnakers-landing.md) distinguish those footprints from NRCan survey elevations, photographic factual references, and original scenery materials.
