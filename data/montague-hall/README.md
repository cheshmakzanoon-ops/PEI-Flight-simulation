# Montague Hall: measured geometry receipt

`native-validation.json` records the production atlas key, bounded public
Natural Resources Canada LiDAR sample, and blocked native roof tests for the
existing footprint. No full point cloud, imagery, third-party visual artwork
or material reproduction is distributed here. Underlying NRCan data are
available under the [Open Government Licence – Canada](https://open.canada.ca/en/open-government-licence-canada).
The separately licensed [OSM orientation/registration subset](../odbl/montague-bridgehead)
has its own receipt. See the [scene QA notes](../../docs/qa/montague-hall.md)
for replay commands and vertical limitations.
